About Arcania

Arcania development started in July of 2023, when I decided I want to learn Borderlands 2 modding. After figuring out how to add custom items with tools like Command Extensions, I decided to create and publish a weapon pack.

The initial version of the mod released in early 2024. At that time, it was just another item pack. The items were poorly balanced, poorly coded, and had ugly skins. :P Version 0.2.0 released about a month later with a few more items, fixes, and drop source changes. At that time, I didn't have a set vision for what I wanted the mod to be - I just knew it was going to be an item pack. I experimented with various things, such as custom rarities for my new gear.

0.3.0, released in September 2024, was Arcania's first 'real' version, which included several unique features such as raid boss item sets, more balanced items overall, the first custom enemy, fixes for Salvador, and decluttered item cards, as well as Python scripts for dynamic loot pools and spawns. It was also the time when the mod gained a bit of public attention - mostly because of JoltzDude139's playthrough of it.

In May of 2026, more than a year after the previous version, 0.4.0 released. It was the biggest update to the mod to date, and the first version of Arcania that made it more than just an item pack, introducing grenade and relic rebalances. It also added a lot more gear, finished item sets for all the raid bosses, improved skins for all the custom gear, and a bunch more custom enemies. The update set the scope for future releases, which would include rebalances for several other aspects of the game as well as features like general reskins and consistency changes.

0.5.0 is the current version. It introduced balance and consistency changes for all vanilla and custom shields. It also changed the development and release cycle of the mod - instead of doing massive updates that cover many different things, the mod will receive smaller, more focused patches.

A new update is currently in progress, featuring rebalances, reskins, and consistency fixes for vanilla weapons. While the mod is slowly becoming a pretty large overhaul, I still actively try to keep it as close to vanilla feel as possible.
